Weather Data Analysis with Python

This project was developed as part of the MLDS Week 1 learning activities. It explores data collection, processing, parsing, and analysis using Python.

Project Overview

The project includes practical exercises involving web scraping, weather APIs, structured data formats, and automated testing.

Features

Web Scraping: Extracting information from web pages.

Weather API: Retrieving weather data using the Open-Meteo API.

Data Processing: Cleaning and analyzing weather information with Python.

CSV: Exporting structured weather data to CSV files.

JSON: Storing weather data in JSON format.

XML: Parsing XML data.

Regular Expressions: Extracting and validating text patterns.

Automated Testing: Verifying the implementation with pytest.
